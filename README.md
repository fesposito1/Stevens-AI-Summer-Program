# Stevens-AI-Summer-Program

Sports Stats Search
A Flask web app for looking up teams and players across sports — soccer, basketball, football, hockey, baseball, golf, tennis, and more — via TheSportsDB free API. It also lets you create an account to log your own sport-specific personal stats, compare yourself to pro athletes, see how you rank on a leaderboard shared across everyone using the app, chat with an AI coach, and get simple trend projections.

Code lives in sports-stats-app/.

Quick start
Live app: https://sports-stats-app-1sqi.onrender.com/ — just open it in a browser and create an account.

Or run from source (local development):

cd sports-stats-app
pip install -r requirements.txt
python app.py
See sports-stats-app/README.md for full details — features, data storage, how the projections model works, and how the cloud deployment works.
