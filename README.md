# Stevens-AI-Summer-Program

Sports Stats Search
A desktop app (Flask backend + a native window via pywebview) for looking up teams and players across sports — soccer, basketball, football, hockey, baseball, golf, tennis, and more — via TheSportsDB free API. It also lets you create an account to log your own sport-specific personal stats, compare yourself to pro athletes, see how you rank on a leaderboard against other users, and get simple trend projections.

Code lives in sports-stats-app/.

Quick start
Double-click sports-stats-app/dist/SportsStatsApp.exe — no Python install required.

Or run from source:

cd sports-stats-app
pip install -r requirements.txt
python app.py
See sports-stats-app/README.md for full details — features, data storage, how the projections model works, and how to rebuild the standalone .exe.
